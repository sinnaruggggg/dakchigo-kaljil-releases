# 닥치고 칼질 Android 업데이트

[최신 릴리스](https://github.com/sinnaruggggg/dakchigo-kaljil-releases/releases/latest)에서 APK를 받으세요. 현재 3.6.1(135)이 공개되어 있습니다.

정식 APK는 정식 서명 설치본용, `-legacy.apk`는 d1e6e387… debug 서명 설치본용입니다. 더 오래된 일부 서명은 호환되지 않습니다. APK 서명이 다르면 앱을 삭제해 맞추지 말고 해당 서명용 파일이 필요합니다.

3.6.0(134) 정식 APK는 자동업데이트가 꺼져 있어 이번에는 직접 설치해야 합니다. 이번 GitHub135 빌드부터 최신 릴리스의 `version.json` 또는 `version-legacy.json`을 통해 같은 서명의 업데이트를 받습니다. Android 설치 확인과 필요 시 설치 권한 허용은 사용자 조작이 필요합니다. 일반 Play 빌드의 APK updater는 기본적으로 꺼져 있습니다.

APK 배포 전용 저장소이며 소스·계정·저장 데이터는 포함하지 않습니다. 남은 4K 자산 검사 초과, 장시간 성능 실패, 서버 타이밍 미반영은 릴리스 설명을 확인하세요. GitHub 업데이트 배포가 출시 검수 전체 통과를 뜻하지 않습니다.
